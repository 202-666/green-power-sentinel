# 绿电哨兵 (Green Power Sentinel)

> 基于飞书生态的四 Agent 协作焚烧炉设备故障预警系统
> 飞书 AI 先锋人才大赛 · 高能环境命题

## 一句话介绍

零新增硬件、全飞书原生、单厂两周部署的轻量级预测性维护方案。

## 核心指标（模拟数据已验证）

| 指标 | 结果 | 目标 | 状态 |
|---|---|---|---|
| 故障检出率 **Recall** | **91.03%** | > 90% | ✅ PASS |
| **F1** 综合评分 | **0.8864** | > 0.7 | ✅ PASS |
| 正常数据误报 (FP) | **0 次 / 43200 行（30 天）** | < 5 次/30 天 | ✅ PASS |

详细数据见 [`docs/W7_性能报告.md`](docs/W7_性能报告.md)。

## 快速开始

```bash
pip install -r requirements.txt

# 运行 153 个单元测试（2026-08-05 全量复跑：153 通过/0 失败）
python -m pytest tests/ -v

# 运行 Demo 生成预警卡片与运维建议
python demo/run_demo.py

# 一键复现 W7 性能数据
python tests/benchmark_w7.py
```

## 项目结构

```
green-power-sentinel/
├── config/          # YAML 配置外部化（阈值/规则/知识库/全局配置）
├── core/            # 核心流水线（数据清洗、四 Agent 协调、运维建议）
├── data/            # 模拟数据生成器 + 飞书多维表格 Schema
├── demo/            # 可运行 Demo + 可视化仪表盘 (dashboard.html)
├── docs/            # W7 性能报告 + W8 技术文档
├── feishu/          # 飞书 OpenAPI 封装（认证/多维表格/消息卡片）
├── models/          # 四类检测器 + 综合评分器
├── tests/           # 单元测试 + W7 基准复现脚本
├── .gitignore
├── LICENSE
├── README.md
└── requirements.txt
```

| 目录 | 一句话说明 |
|---|---|
| `config/` | 阈值/规则/知识库全部 YAML 外部化，无硬编码，便于跨厂复用 |
| `core/` | 数据清洗 + 四 Agent 流水线协调 + 运维建议生成 |
| `data/` | 模拟数据生成器（3 类故障 + 1 类正常）+ 飞书多维表格 Schema |
| `demo/` | 一键运行 Demo + 浏览器仪表盘（可视化预警时间线） |
| `docs/` | W7 性能报告（Recall/F1 验收）+ W8 技术文档（架构/数据流/模块说明） |
| `feishu/` | 飞书 OpenAPI 封装：OAuth 认证、多维表格读写、消息卡片推送 |
| `models/` | 阈值/趋势/波动/关联 四检测器 + 综合评分器（向量化实现） |
| `tests/` | 132 个单元测试（基线 e1cbc42 复跑：130 通过 / 2 失败，见 FEI-7）+ W7 基准复现脚本 |

## 技术栈

- **Python 3.10+**
- **Pandas / NumPy / SciPy** — 数据处理与异常检测
- **scikit-learn** — 趋势建模
- **PyYAML** — 配置外部化
- **飞书 OpenAPI** — 多维表格 + 消息卡片（原生集成，零新增硬件）

## 设计亮点

1. **配置化架构** — 阈值/规则/知识库全部 YAML 外部化，无硬编码，单厂配置 < 1 天
2. **四 Agent 协作流水线** — 清洗 → 检测 → 评分 → 建议，职责清晰可独立替换
3. **向量化性能优化** — 关联检测 176× 加速，全量 43200 行检测 < 41s（1056 rec/s）
4. **三级预警回填机制** — red/orange/yellow 等级映射 + 持续性过滤，正常数据零误报
5. **飞书原生落地** — 消息卡片直接推送群聊，多维表格记录工单，无需额外运维系统
